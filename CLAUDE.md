@AGENTS.local.md

The project's agent instructions live in `AGENTS.md` so that every coding assistant
reads the same file. Keeping a second copy here would let the two drift apart. Edit
`AGENTS.md`, not this file.

`AGENTS.local.md` holds machine-specific paths and is untracked, so it is absent in a
fresh clone. A missing import is ignored.
